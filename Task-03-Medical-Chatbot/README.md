# 🩺 Medical Chatbot

## Overview
A simple AI-powered Medical Chatbot developed using Python and Streamlit. The chatbot provides general health guidance based on user-entered symptoms. It is intended for educational purposes only.

## Features
- Symptom-based health guidance
- Interactive Streamlit interface
- Simple and user-friendly design
- Educational medical disclaimer

## Technology Stack
- Python
- Streamlit
- Git
- GitHub


## Running the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```

This chatbot is for educational purposes only and should not be considered a substitute for professional medical advice.
