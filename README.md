# EduLumos Artificial Intelligence Internship

This repository contains the projects completed as part of my Artificial Intelligence Internship at EduLumos.

## Projects

### Task 1 – Face Detection using OpenCV
- Detects human faces in real time using OpenCV.
- Uses Haar Cascade Classifier.
- Displays the number of detected faces.
- Built with Python and OpenCV.

## ✅ Task 2 – AI Fake News Detection

- NLP-based Fake News Detection using TF-IDF and Logistic Regression
- Interactive Streamlit web application
- Confidence score prediction
- Built with Python, Scikit-learn, Pandas, and Streamlit

## ✅ Task 3 – Medical Chatbot

- AI-powered symptom-based medical chatbot
- Interactive Streamlit interface
- Provides preliminary health guidance
- Built with Python and Streamlit
